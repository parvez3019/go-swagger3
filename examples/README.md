# Framework examples

Minimal mounts of Swagger UI for specs generated by go-swagger3.

| Example | Adapter module |
|---------|----------------|
| [nethttp](nethttp/) | `github.com/parvez3019/go-swagger3/swagger` |
| [gin](gin/) | `github.com/parvez3019/go-swagger3/swagger/gin` |
| [echo](echo/) | `github.com/parvez3019/go-swagger3/swagger/echo` |
| [chi](chi/) | `github.com/parvez3019/go-swagger3/swagger/chi` |

Other adapters (same `WrapHandler(spec)` pattern):

- `swagger/mux` — gorilla/mux
- `swagger/fiber` — Fiber
- `swagger/hertz` — Hertz
- `swagger/buffalo` — Buffalo
- `swagger/flamingo` — Flamingo (`http.Handler`)
- `swagger/atreugo` — Atreugo

```bash
cd examples/gin && go mod tidy && go run .
# open http://localhost:8080/swagger/index.html
```
